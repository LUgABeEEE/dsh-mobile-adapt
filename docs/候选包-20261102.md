任务：t6。只改本仓库，不装扩展、不发 PR、不 commit。所有结论分【事实】/【推断】/【未验证】。

## 0. 结论

**选 `dsh-context`（bowenliang123）做定向包 `dsh-context-mobile`**，只勾 `hit-target`。理由按优先级：

1. **它是三个候选里唯一能被现有 harness 量到的主槽面板**：主面板注册在 `conversation.view`（`src/client/index.ts:64-65`），渲染进 `[data-slot="main"]`；`check-pack` 的 `hit-target` 断言正好量这个容器。【事实】
2. `dsh-agent-teams` 的面板在 `shell.overlay` / 右栏 tab（`lib/client.js:4531,4549`），`dsh-purge` 的 dock 也是 `position:fixed` 的 overlay（`client.js:1010`）——都**不在 `[data-slot="main"]`**，现有 `hit-target` 断言量不到，做包只能靠改 harness 或写不可验证的声明。【事实】
3. `dsh-context` 的类名是 `lc-*`（不是每次构建都变的 CSS Module 哈希），但收录标准仍禁止点名第三方类名；它自己的 `data-lc-*` 属性命名空间（`data-lc-trend` / `data-lc-bars` / `data-lc-tip` / `data-lc-current` / `data-lc-key` / `data-lc-clearable`）可以做**定位桥**（包内 `mobile.js` 打自有 `data-dshm-context-panel`），CSS 不碰插件类名。【事实】
4. 它的手机缺口是**命中区**而不是布局：已有容器查询（`overview.css:24`、`base.css:73`）与省略号（`base.css:33-35`），但粒度按钮 11px 字号 / 3px 8px padding（`base.css:42`）、设置胶囊 12px/18px（`overview.css:8`）、搜索框继承 13px（`base.css:49-50`）。【事实：源码；未在真实页量】

包产物：[`packs/dsh-context-mobile/`](../packs/dsh-context-mobile/)；catalog 条目见 `catalog.json`。

## 3. 另外两个候选：可验证性判断 + 需要的 DOM 证据清单

### 3.1 `@nanmicoder/dsh-agent-teams` 0.1.28（npm tarball `client.js` 与安装副本 sha256 一致 `6152bc12…65f6`）

- **判定：当前不可做可验证的定向包（upstream / 需 harness 扩展）。**
- 三个 UI 面都不在 `[data-slot="main"]`：右栏 tab `sidebar.right.pane.tab`、会话头 `conversation.session.header.actions`、聊天尾卡 `conversation.chat.turnTail`、浮动面板 `shell.overlay`（`lib/client.js:4518,4524,4531,4549`）。`check-pack` 的 `hit-target`/`floater` 断言都量不到它们。【事实】
- 浮动面板根有 `data-agent-teams-activity`（`lib/client.js:3412`），但**不是** `data-dsh*`，静态层不允许 CSS 点名；可以用包内 JS 做定位桥，但面板在 overlay 里，量不到就等于没有验收。【事实】
- 420px 会话侧移在窄屏已被插件自己关掉：`@media (width<=960px){html[data-agent-teams-panel-open] [data-phase=active]{padding-right:0}}`（`lib/client.js:780` 的 CSS 字符串）——原先"手机被挤走"的假设不成立，需要撤回。【事实】
- **需要的 DOM 证据**：① 390×844 真机/专用页下浮动面板的 `getBoundingClientRect()` 与面板内控件逐个尺寸；② 面板根是否能获得 `data-dsh-agent-teams-root`（上游 PR，见清单 §4.2）；③ `shell.overlay` 插槽在当前 dsh-mobile 版本的实际 DOM 结构与 `data-slot`/`data-*` 属性；④ `conversation.session.header.actions` 按钮在手机上的实际尺寸（是否有 44px 缺口）。
- **如果要做**：最小范围是给 `shell.overlay` 增加一个可验证的 overlay 断言组（新能力，例如 `overlay-hit-target`），加上上游把面板根改名 `data-dsh-*`。不是本任务的仓库改动范围。

### 3.2 `dsh-purge`（GitHub `YuJunZhiXue/dsh-purge`，master `client.js` sha256 `26286501…73fc`；**npm registry 404，没有 npm 制品**）

- **判定：不可做（blocked，除非上游改名）。**
- 它的 `data-dsh-*` 全部打在 `<style>` 标签上，不是面板 DOM：`document.querySelector('style[data-dsh-purge-ui="1"]')`（`client.js:8733`）、`data-dsh-purge-drill`（`:8742`）、`data-dsh-purge-dock-w`（`:8746`）。面板用 `.dshp-*` 类名 + `data-testid`。【事实】
- dock 是 `position:fixed` + `width:var(--dshp-dock-w,620px)` + `min-width:380px`（`client.js:1010`），启动球 36px 高（`client.js:1012`）——在 390px 视口上**确实会溢出**，但选择器只能靠 `.dshp-*` / `data-testid`，收录标准不允许。【事实：CSS 声明；未在浏览器量】
- **需要的 DOM 证据**：① 390×844 下 `.dshp-dock` 的 `rect`（左缘是否负、右缘是否 >390）；② dock 内控件逐个尺寸；③ `data-testid` 的稳定值清单（用于判断能否作为可接受的公开契约）；④ 上游是否愿意把 dock 根改成 `data-dsh-purge-root`（清单 §4.4 已提）。
- **如果要做**：需要上游改名 + 一个新的 overlay/固定层断言口径；本任务不建包。
