## 1. F1：host-probe 全量断言

### 改法（`tools/check-pack.mjs`）

- `measurePage()` 的每个控件新增 `minHeight`（computed `min-height`），不再单独返回
  `buttonMinHeight` / `inputMinHeight` 两个采样值。
- `checkHostGate()` 使用 `retreated.controls` / `withHost.controls` 与 `baseline.controls`
  **同序同量**逐项比较；数量不一致直接 `runtime.hostGate.probe` FAIL（同一 fixture 应当同序同量）。
- 三条断言（ID 不变，回归测试引用不变）：
  1. `runtime.hostGate.floor-retreated`：**每个**控件的 computed `min-height` 回到无包基线（容差
     `EPSILON`，`auto` 视作同值）；失败时报告「N/总数 个控件的 min-height 没有回到基线（最小 Xpx）」+ 前 3 个。
  2. `runtime.hostGate.no-shrink`：**每个**控件渲染高度 ≥ 无包基线 − 2（允许 16px 字号固有高度差）。
  3. `runtime.hostGate.host-floor-kept`：注入 0.8.1 宿主地板后，**每个**受地板覆盖的控件
     高度 ≥ `HIT_TARGET − EPSILON` 且 ≥ 基线 − 2；不受覆盖的控件（textarea / switch / checkbox /
     radio / slider / 被排除的 input type）只要求 ≥ 基线 − 2。覆盖判定 `hostFloorCovers()` 照
     `lib/mobile-layout.js:507` 的 `:is(button,[role=button],select,input:not(...))` 与 `:not([role=…])` 写。
- `host-probe` 的两段（sentinel / 注入宿主地板）不变；`own-state` 仍按任务允许 SKIP。

### F1 绕过包输出（只把 `[role="group"] button` 在宿主状态下压到 20px）

构造方式与 verifier §1.3 相同，只是用允许的 `.dshm-*` 类提高特异性（避免静态层误报）：

```css
@media (pointer: coarse) {
  :root:not([data-dsh-adapt="off"]):not(.dshm-bp1):not(.dshm-bp2):not(.dshm-bp3):not(.dshm-bp4):not(.dshm-bp5):not(.dshm-bp6)
    .dshm-main[data-dsh-panel="1"] [data-slot="main"] [data-dshm-context-panel="1"] [role="group"] button {
    min-height: 20px !important;
  }
}
```

```
PASS  宿主接管后全部 10 个控件的 min-height 回到基线（最小 28px，容差 0.5px）
PASS  宿主接管后全部 10 个控件不小于无包基线（最小高度 17px，允许 ±2px 字号固有高度差）
FAIL  本包把宿主的地板压小了：4 个不达标（覆盖 10/10 个控件，最小高度 20px）：
      button #2 20px < 44px；button #3 20px < 44px；button #4 20px < 44px
RESULT FAIL（41 passed · 1 failed · 1 skipped）
```

注意：该规则的 `[data-dsh-panel="1"]` 前缀使它只在宿主接管阶段生效，所以 `floor-retreated` 仍 PASS；
正是 `host-floor-kept` 的全量遍历把它抓住。修复前（只采样第一个按钮 = 设置按钮 44px）同一包是 42/0/1。
