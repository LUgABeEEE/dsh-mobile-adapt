# 真机实测清单（外部贡献者）

> 用途：把「手机/平板上适配包到底有没有用」变成可复核的数据，而不是一句「我这边好了」。
> 背景：dsh-mobile **0.8.1** 起宿主自带粗指针 44px 面板地板；本仓库的适配包是**选装**。
> 所以每一组都要有 **装包 / 不装包** 的对照，否则无法判断是宿主还是包在起作用。

## 0. 需要准备什么

- 一台手机 + 一台平板（当前目标：小米 17 Pro Max、小米 Pad 9 Pro Max）。
- 已安装 dsh-mobile Android App；能连到测试网关（局域网直连或 USB 转发，见仓库 `docs/真机验证.md` §3）。
- 已安装当前适配插件：仓库根执行

  ```bash
  npm run bundle
  node tools/install.mjs plugin build/dsh-ui-optimizer --yes
  ```

- 能卸载它（对照组）：`node tools/install.mjs --uninstall dsh-ui-optimizer --yes`（可随时装回）。

## 1. 必填环境（每个设备一段）

| 字段 | 怎么取 |
| --- | --- |
| 设备型号 / 系统版本 | 设置 → 关于手机 |
| WebView 版本 | 设置 → 应用 → Android System WebView（或 `chrome://version`） |
| App 版本 | App 内「关于」/`android:versionName` |
| 屏幕 CSS 尺寸与 DPR | `screen.width/height`、`devicePixelRatio`（Chrome 远程调试或任意 JS 环境） |
| 网关 | 网址与 dsh-mobile 版本（0.8.1 / 其它） |
| DSH 版本 | 设置 → 关于 |
| 连接方式 | 局域网 / USB 反代 / 远程通道（写明） |
| 是否外接键鼠 | 是/否（影响 `pointer: coarse` 判定） |

## 2. 必测面板（至少两个第三方面板 + 一个原生页）

- `Context Insights`（dsh-context）
- `Todos`（dsh-global-todo）
- 自选一个装了的第三方面板
- 原生会话页（对照组）

每个面板都要有：**装包** 与 **不装包** 两张截图 + 下面这组数字。

## 3. 每组要记的数字

| 指标 | 取值方式 |
| --- | --- |
| 面板内可点控件总数 / 最小边 / `<44px` 数量 | `[data-slot="main"] :is(button,[role="button"],input,select,textarea)` 逐个取 `getBoundingClientRect()` 最短边 |
| 面板左右缘 | `.dshm-main` 或面板根 `getBoundingClientRect()` 的 `left/right` |
| 横向溢出 | `document.documentElement.scrollWidth > innerWidth` |
| 浮动控件让位 | `getComputedStyle(document.documentElement).getPropertyValue('--dshm-floaters')` |
| 软键盘 | 弹出前后 `innerHeight` / `visualViewport.height` |
| 抽屉行高 | 打开抽屉，量 `[data-slot="sidebar"]` 内按钮高度 |
| 返回栏高度 | `.dshm-panelNav` 内按钮高度 |

## 4. 对照与判定

1. **装包**：`core-panel` 的高度地板在 0.8.1 上会按宿主门阀退让（宿主写 `data-dsh-panel`），
   所以「装包后数字不变」可能是**正常的**；要看的是 `min-width:44`（图标按钮）、底部安全区、
   floaters 让位、抽屉行 36→44。
2. **不装包**：卸载插件、等 3 秒（宿主 2 秒轮询）再测同一组。对照组才有说服力。
3. **opt-out**：装包状态下给 `<html>` 加 `data-dsh-adapt="off"`，数值应回落到对照组水平。
4. 结论按 `min ≥ 44`、`under44 = 0`、`overflow = false`、「键盘弹出后主操作仍可见」判定。

## 5. 截图与提交

- 命名：`<设备>-<面板>-<装包|不装包>-<竖|横>.png`
- **不要截聊天正文**；只截面板、外壳、输入栏即可，注意隐去账号/会话内容。
- 提交方式：在本 issue 下回复「设备 + 数字 + 截图」，或按同样结构提一个
  `docs/真机验证/<日期>-<设备>.md` 的 PR。
- 结果会进入 `catalog.json` 的 `evidence.have`；**不会**因此直接改包行为，改行为需要另开 PR。

## 6. 已知边界（不用重复踩）

- 本 App 版本的 `env(safe-area-inset-*)` 在部分机型恒为 0（内缩由原生布局消化），不要把它当作包失效。
- 无头浏览器里软键盘不收缩，键盘相关结论**只能真机**。
- 0.8.0 与 0.8.1 的宿主行为不同：报告里必须写清网关版本。
